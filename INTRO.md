# Multi-Agent Session Manager

**Định hướng:** VS Code Extension theo dõi và quản lý session từ nhiều AI agent (Claude, Cursor, Gemini, Devin, v.v.) trong cùng một giao diện thống nhất.

**Tính năng chính:**
- 🤖 Hỗ trợ đa AI agent (Claude, Cursor, Gemini)
- 📊 Dashboard thời gian thực theo dõi trạng thái (Running, Need Accept, Done)
- 🔍 Phân tích token, branch git, repo
- 🎯 Filter và switch nhanh giữa các session
- 📱 Hiển thị trên Activity Bar, Explorer, Source Control

**Mục tiêu:** Giúp developer làm việc hiệu quả với nhiều AI agent cùng lúc mà không bị lạc session.

**Trạng thái:** Phase thiết kế kiến trúc - Sẵn sàng refactoring từ Claude-only sang Multi-Agent.
